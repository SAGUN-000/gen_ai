# 🚀 DSA LLM — AI Data Structures & Algorithms Tutor

An intelligent, full-stack AI tutor specialized in Data Structures and Algorithms. Built with React 19, Node.js/Express, Prisma, PostgreSQL, and Google Gemini AI.

---

## 📖 Feature Documentation

For an easy-to-read, comprehensive breakdown of all features, check out:
👉 **[FEATURES.md](./FEATURES.md)**

---

## ✨ Highlights

- 🤖 **Specialized DSA Tutor**: Focused specifically on algorithms, data structures, and Big-O complexity analysis powered by Gemini 3.5 Flash.
- 🧠 **Smart Context & Memory**: Automatic rolling summarization every 10 messages + sliding recent context window to preserve long-term chat memory while minimizing token costs.
- 💬 **Multi-Session Chat**: Create multiple conversations with automatic topic titling and sidebar history.
- 🔐 **Authentication & Security**: User accounts with bcrypt password hashing, JWT authentication, and private user data isolation.
- 🎨 **Modern Dark Interface**: Sleek dark UI built with Tailwind CSS v4, quick-start question prompts, and responsive design.

## 🛠️ Quick Start

### 1. Server
```bash
cd server
npm install
npm run dev
```

### 2. Client
```bash
cd client
npm install
npm run dev
```

Visit `http://localhost:5173` to get started.
